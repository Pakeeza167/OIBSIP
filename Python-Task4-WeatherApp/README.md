# Weather App

## Objective

To create a Python-based Weather App that fetches and displays current weather information for a city using a weather API.

## Steps Performed

1. Took the city name as input from the user.
2. Connected the application to the weather API.
3. Sent a request to retrieve weather information.
4. Processed the API response.
5. Displayed the temperature and other weather details.
6. Tested the application with different cities.

## Tools Used

- Python
- VS Code
- Requests library
- OpenWeatherMap API

## Outcome

A working Weather App was developed that retrieves and displays weather information for different cities.
