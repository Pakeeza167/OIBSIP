# BMI Calculator

## Objective

To create a simple Python program that calculates a person's Body Mass Index (BMI) using their height and weight.

## Steps Performed

1. Took the user's height and weight as input.
2. Calculated BMI using the given values.
3. Displayed the calculated BMI.
4. Tested the program with different inputs.

## Tools Used

- Python
- VS Code

## Outcome

A working BMI Calculator was developed that accepts height and weight and displays the calculated BMI.
