# Random Password Generator

## Objective

To create a Python program that generates random passwords using a combination of letters, numbers, and special characters.

## Steps Performed

1. Took the desired password length as input.
2. Created a collection of letters, numbers, and special characters.
3. Randomly selected characters from the collection.
4. Generated and displayed the password.
5. Tested the program with different password lengths.

## Tools Used

- Python
- VS Code

## Outcome

A working Random Password Generator was developed that creates random passwords based on the user's selected length.
